              One-time replies

              Guide

              Enter one TCP command at a time in the prompt below.

              PING
              Check the connection. The server replies OK PONG.
              SCHEMA
              List fields, types, and permissions. S means stream, R read, and W write.
              GET <field or group>
              Read current values once. Try GET position or GET * for all readable fields.
              SET <field>=<value>
              Write a value over TCP. Separate multiple assignments with spaces to apply them together.
              SUB <port> <group>
              Receive live UDP updates. Use the receive port shown above the command prompt.
              UNSUB <group>
              Stop one subscription. SUB false stops all subscriptions in this tab.
              PUBLISH <group>
              Reserve a writable group for UDP uploads. Try PUBLISH speed.
              PUBSTATUS
              Show accepted UDP packets per publication in its last completed 10-second window.
              UNPUBLISH <group>
              Stop an upload and release its fields for other writers.
              SAMPLE <token> <seq> <field>=<value>
              UDP only. Clicking Publish sends values for the whole group continuously at 60 Hz.
